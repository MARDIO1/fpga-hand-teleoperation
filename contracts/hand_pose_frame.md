# HandPoseFrame v0.2

Produced by fusion for PS debugging and future teleoperation.

| Field | Type | Meaning |
| --- | --- | --- |
| sequence | `uint32` | Source synchronized-frame sequence |
| timestamp_us | `uint32` | Source timestamp |
| position[3] | `float32` | Palm position in metres |
| rotation[9] | `float32` | Row-major 3 by 3 palm rotation |
| bend[5] | `float32` | Reconstructed finger bend |
| spread[5] | `float32` | Bend-coupled inferred finger spread |
| valid_mask | `uint16` | Camera, IMU, inertial prediction and stationary flags |
| valid | `uint8` | Output validity |
| state | `uint8` | Tracking, predict, damp, hold or reacquire |

The single dorsal IMU supplies orientation. Camera input supplies translation only;
finger lateral motion is not observed and `spread` is generated by the shared LUT.
